# 3. En Azure DevOPs:  Crear un service connection
- Project settings:

- Tipo: Azure Resource Manager
- Método: Service principal (automatic)
- Seleccionar Suscripción y RG
- Nombre: appDeployConnection
- Grant access permission to all pipelines


# 4. Crear el deploy en yml
## 4.1. task de prueba
```yaml
      - job: Deploy
        displayName: Deploy
        dependsOn: Build
        pool: local-agent
        steps:
          - script: echo "Deploying..."
```

## 4.2. Buscar credenciales de ACR
- Settings - Access Keys

## 4.3. Crear las credenciales de ACR como secrets

- acrUsername
- acrPassword

## 4.4. Agregar el deploy del Container App
> [Azure web apps](https://learn.microsoft.com/en-us/azure/devops/pipelines/tasks/reference/azure-container-apps-v1?view=azure-pipelines)
```yaml
      - job: Deploy
        displayName: Deploy
        dependsOn: Build
        pool: local-agent
        steps:
          - task: AzureContainerApps@1

            inputs:
              azureSubscription: 'appDeployConnection'
              imageToDeploy: acrapps<ESTUDIANTE>.azurecr.io/${{ parameters.imageName }}:$(Build.BuildId)

              containerAppName: 'app-public-api' # NOMBRE DEL CONTAINER APP
              resourceGroup: <RG_NAME>

              acrUsername: $(acrUsername)
              acrPassword: $(acrPassword)
```

> Best Practice: agregar las credenciales como SECRETS.
