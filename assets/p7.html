01

Repositorio en GitHub

El punto de inicio es el almacenamiento de código. Todo cambio de código subido al repositorio de GitHub mediante git push actúa como el disparador del ciclo.

git push origin main
02

Agente Local & Compilación

Un agente de Azure Pipelines autohospedado en tu máquina local escucha y compila el proyecto de forma automática utilizando las especificaciones de azure-pipelines.yml.

pool: local-agent
03

Dockerización & ACR

El pipeline construye una imagen de contenedor Docker usando el archivo Dockerfile, asignándole una versión definida dinámicamente y subiéndola a Azure Container Registry de manera segura.

docker build -t acrapps.azurecr.io/demo-page:1.0.0 .
04

Despliegue Continuo

El contenedor se descarga en la Máquina Virtual de destino directamente del registro privado (ACR) y se ejecuta exponiendo el puerto del servidor (3001), completando el proceso.

docker run -d -p 3001:3000 acrapps.azurecr.io/demo-page:1.0.0
