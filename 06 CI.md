- Conectar con Github
- Seleccionar el proyecto
- Crear azure-pipelines.yml

```yaml
trigger:
- main

resources:
- repo: self

variables:
  tag: '$(Build.BuildId)'
  imageName: 'public-api'

stages:
- stage: Build
  displayName: Build image
  jobs:
  - job: Build
    displayName: Build
    pool:
      vmImage: ubuntu-latest

    steps:
    - task: Docker@2
      displayName: Build an image
      inputs:
        repository: $(imageName)
        command: build
        dockerfile: '**/qa.dockerfile'
        tags: $(tag)

```

# 4. Agregar variables de entorno

> Para este ejemplo el valor debe ser registrado con slash y comillas, ej: `\"APP_NAME\"`.

- Pipelines - Library
- Add Variable Group
- Name: CICD
- + Add:
  - Name: appVariable
  - Value: `"{ \"APP_NAME\":\"publicAPI\", \"NODE_ENV\":\"qa\", \"NODE_PORT\":\"3000\", \"TOKEN_LIMIT\":\"7d\", \"TOKEN_SECRET\":\"PASS\" }"`
- Change variable type to secret. (ícono de "lock")
- Guardar

## 4.1. Actualizar el yml agregando las variables.
```yaml
trigger:
  - main

resources:
  - repo: self

variables: <---------------------- AGREGA LAS VARIABLES
  - group: "CICD"
  - name: app_var
    value: $[variables.appVariable]
parameters:
  - name: tag
    default: "$(Build.BuildId)"
  - name: imageName
    default: "public-api"

stages:
  - stage: Build
    displayName: Build image
    jobs:
      - job: Build
        displayName: Build
        pool: local-agent

        steps:
          - script: |
              echo "var=$(app_var)"

          - task: Docker@2
            displayName: Build an image
            inputs:
              repository: ${{ parameters.imageName }}  <---------------------- AGREGA LAS VARIABLES
              command: build
              dockerfile: "**/qa.dockerfile"
              tags: ${{ parameters.tag }} <---------------------- AGREGA LAS VARIABLES
              arguments: '--build-arg APP_ENV="$(app_var)"'

```

## 5.2. Service Connection
En azure Devops:
- Project Settings

- Type Docker Registry
- Check Azure Container Registry
- Authentication Type: Service Principal
- Subscription
- ACR
- Name: registryConnection
- Check Grant Access

## 5.3. Agregar el nuevo task al yml e integrar el registry de ACR
```yaml
trigger:
  - main

resources:
  - repo: self

variables:
  - group: "CICD"
  - name: app_var
    value: $[variables.appVariable]
parameters:
  - name: tag
    default: "$(Build.BuildId)"
  - name: imageName
    default: "public-api"

stages:
  - stage: Build
    displayName: Build image
    jobs:
      - job: Build
        displayName: Build
        pool: local-agent

        steps:
          - script: |
              echo "var=$(app_var)"
              echo "tag= ${{ parameters.tag }}"

          - task: Docker@2
            displayName: Build an image
            inputs:
              command: build
              repository: ${{ parameters.imageName }}
              dockerfile: "**/qa.dockerfile"
              tags: ${{ parameters.tag }}
              arguments: '--build-arg APP_ENV=$(app_var)' <------------------------------ build args
							containerRegistry: 'registryConnection' <------------------------------ repository service connection

          - task: Docker@2 <------------------------------ push task
            displayName: 'Push Docker Image'
            inputs:
              command: 'push'
              containerRegistry: 'registryConnection' <------------------------------ repository service connection
              repository: ${{ parameters.imageName }}
              tags: ${{ parameters.tag }}
```
