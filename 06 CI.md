# 5. Agregar variables de entorno

> Para este ejemplo el valor debe ser registrado con slash y comillas, ej: `VERSION`.

- Pipelines - Library
- Add Variable Group
- Name: CICD
- + Add:
  - Name: appVersion
			- Value: "1.0.1"
- Change variable type to secret. (ícono de "lock")
- Guardar

## 5.1. Actualizar el yml agregando las variables.
```yaml
trigger:
  - main

resources:
  - repo: self

variables: # <---------------------- AGREGA LAS VARIABLES
  - group: "CICD"
  - name: appVersion
    value: $[variables.appVersion]
parameters:
  - name: tag
    default: "$(Build.BuildId)"
  - name: imageName
    default: "demo-page"

stages:
  - stage: Build
    displayName: Build image
    jobs:
      - job: Build
        displayName: Build
        pool: local-agent

        steps:
          - script: |
              echo "var=$(appVersion)"

          - task: Docker@2
            displayName: Build an image
            inputs:
              repository: ${{ parameters.imageName }}  # <---------------------- AGREGA LAS VARIABLES
              command: build
              dockerfile: "**/Dockerfile"
              tags: ${{ parameters.tag }} # <---------------------- AGREGA LAS VARIABLES
              arguments: '--build-arg VERSION="$(appVersion)"'

```

## 6.3. Agregar el nuevo task al yml e integrar el registry de ACR
```yaml
trigger:
  - main

resources:
  - repo: self

variables:
  - group: "CICD"
  - name: appVersion
    value: $[variables.appVersion]
parameters:
  - name: tag
    default: "$(Build.BuildId)"
  - name: imageName
    default: "demo-page"

stages:
  - stage: Build
    displayName: Build image
    jobs:
      - job: Build
        displayName: Build
        pool: local-agent

        steps:
          - script: |
              echo "var=$(appVersion)"
              echo "tag= ${{ parameters.tag }}"

          - task: Docker@2
            displayName: Build an image
            inputs:
              command: build
              repository: ${{ parameters.imageName }}
              dockerfile: "**/Dockerfile"
              tags: ${{ parameters.tag }}
              arguments: '--build-arg VERSION=$(appVersion)' # <------------------------------ build args
							containerRegistry: 'registryConnection' # <------------------------------ repository service connection

          - task: Docker@2 # <------------------------------ push task
            displayName: 'Push Docker Image'
            inputs:
              command: 'push'
              containerRegistry: 'registryConnection' # <------------------------------ repository service connection
              repository: ${{ parameters.imageName }}
              tags: ${{ parameters.tag }}
```

VM_NAME=<VM_NAME>

echo "Resource Group: $RESOURCE_GROUP"
echo "VM Name: $VM_NAME"

  --resource-group $RESOURCE_GROUP \
  --name $VM_NAME \
  --query identity.principalId -o tsv)

echo "Identity Object ID: $IDENTITY_OBJECT_ID"

az role assignment create \
  --assignee $IDENTITY_OBJECT_ID \
  --role acrpush \
  --scope $(az acr show --name $ACR_NAME --query id -o tsv)
